# Вычисление групп кручения рациональных эллиптических кривых методом предварительной калибровки

Репозиторий реализует точное вычисление группы кручения для невырожденных целочисленных коротких моделей Вейерштрасса `E_(a,b): y^2 = x^3 + ax + b` над `Q`, где `a,b in Z` и `4a^3 + 27b^2 != 0`. Публичный API принимает только built-in Python `int` и явно отклоняет сингулярные и неподдерживаемые входы.

## Алгоритм и граница оракула

Собственный точный алгоритм перечисляет рациональные точки 2-кручения по корням `x^3 + ax + b`, перечисляет и проверяет 3-кручение через третий многочлен деления, строит целочисленных кандидатов Луца–Нагелля из квадратных делителей дискриминанта, затем точно проверяет порядки точек, замыкает порождённую подгруппу, выбирает детерминированные образующие и определяет тип по списку Мазура.

`compute_torsion()` в `src/rational_torsion/core.py` — собственный точный алгоритм; он не вызывает `torsion_subgroup()` или `torsion_order()`. `sage_reference()` в `src/rational_torsion/reference.py` — изолированный эталонный оракул и единственный модуль, которому разрешён вызов `torsion_subgroup()`. Собственный алгоритм намеренно использует SageMath 10.8 для точной рациональной арифметики, факторизации, построения кривой и сложения точек. Программный вклад состоит в точном алгоритме, явной границе реализации, детерминированной калибровке и воспроизводимой проверке по SageMath; новая теорема не утверждается.

## Среда и проверка

Команды выполняются из корня репозитория:

```bash
conda env create -f environment.yml
conda activate rational-elliptic-torsion-calibration
sage -python -m pip install --no-deps -e .
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src sage -python -m pytest -p no:cacheprovider -q
sage -python -m compileall -q src scripts tests

PYTHONPATH=src sage -python scripts/validate_mazur.py \
  --input data/mazur_representatives.csv \
  --output results/mazur_validation.csv

PYTHONPATH=src sage -python scripts/validate_grid.py \
  --input data/coefficient_grid.csv \
  --output results/grid_validation.csv

PYTHONPATH=src sage -python scripts/reproduce.py \
  --seed 20260220 \
  --sample-size 10000 \
  --cases data/calibration_cases.csv \
  --output results/calibration_summary.csv \
  --max-seconds 3600

PYTHONPATH=src sage -python scripts/verify_results.py
```

## Результаты

| Файл | Содержание |
|---|---|
| `results/mazur_validation.csv` | 15 фиксированных представителей: собственные тип, порядок, точки и образующие, тип и порядок Sage, статус совпадения. |
| `results/grid_validation.csv` | Свежая проверка всех 438 невырожденных пар коэффициентов в `[-10,10]^2`. |
| `results/calibration_summary.csv` | Типизированная детерминированная сводка для 15 курированных и 10 000 уникальных псевдослучайных невырожденных случаев с фиксированным seed, покрытием, отпечатками и записями расхождений. |
| `results/environment.json` | Обезличенные факты о канонической среде и платформе без имени пользователя и имени узла. |

Канонические выходные критерии: 15/15 совпадений на представителях Мазура, 438/438 совпадений на сетке, 10,015/10,015 совпадений в калибровке, все 15 типов Мазура покрыты, ноль расхождений.

## Границы интерпретации

Сетка из 438 кривых и калибровочные 10 015 случаев являются валидационными наборами: они не являются доказательством универсальной корректности и не являются оценкой распространённости типов кручения. Курированные 15 случаев обеспечивают покрытие редких типов, поэтому их частоты не следует интерпретировать как естественное распределение.

Знак, порядок и базис образующих не являются критериями тождества группы. Детерминированные собственные образующие должны порождать полную подгруппу, но не объявляются базисом Sage или инвариантным базисом.

Фикстуры `Cremona_66c1_short_model`, `Cremona_15a1_short_model` и `Cremona_210e2_short_model` — короткие целочисленные модели с буквальными метками происхождения `66c1`, `15a1` и `210e2`; для них не утверждается, что они являются глобальными минимальными моделями. Генерация кандидатов Луца–Нагелля выполняет факторизацию дискриминанта, поэтому время зависит от коэффициентов и сложности факторизации. `--max-seconds 3600` — операционный потолок, а не бенчмарк.
